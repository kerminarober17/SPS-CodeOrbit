What happens when a value changes?

A variable acts like a labeled box that can hold a value.

When you assign a new value to a variable, the old value is replaced.

Any output or calculation that uses that variable will reflect the new value.

See it in action

Python
1 score = 10
2 score = 20
3 print(score)
What happens here? We create a variable called score and give it 10. Then we change it to 20. When we print(score), Python shows the current value, which is 20.
